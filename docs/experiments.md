# 比較した代替案

設計を決めるために比較した構成と、その結果です。設定ファイルは `configs/experiments/`、分析ツールは `scripts/diagnostics/` にあります。
数値は bits49 テスト（未知話者 20 名、364 発話）の clean・BER 0 条件の PESQ-NB です。

## 現在の構成に含まれる要素

| 要素 | 効果 |
|---|---|
| BitToken フロントエンド（位置埋め込み＋MLP＋時間方向 ConvNeXt） | 先行手法の dequantizer に対し、mel 回帰 probe で −1.2 dB、PESQ +0.25（両バックエンド） |
| クリーン音声による mel 条件ボコーダーの事前学習 | 正解 mel からの再合成 PESQ 3.70。学習の初期値になり、ペア録音を消費しない |
| 小型 iSTFT バックエンド（Parallel WaveGAN の代替） | 学習更新 1.7 倍、推論 18 倍速、品質は同等以上 |
| フロントエンドの幅 384 / 8 ブロック（幅 256 / 6 ブロックから） | +0.15 |
| 学習時のビット誤り付加 0〜2 % | BER 1〜3 % で頑健、clean は不変 |
| mel ブリッジ＋凍結ボコーダー | 全体の共同微調整と同等。学習対象はフロントエンドのみ |
| 周期性ヘッド（log-F0・有声度） | 全条件で +0.05 |
| 帯域別非周期性ヘッド（5 帯域） | さらに +0.05（2.587） |

## 比較した代替案

| 構成 | 結果 | 備考 |
|---|---|---|
| 先行手法の PWG ＋ 単一の PWG 識別器 | 識別器が学習しない（D(real)≈D(fake)） | MPD/MRD ＋ feature matching に置換 |
| PWG ＋ 事前学習済み識別器 | 不安定（識別器損失 → 0.3） | |
| 相互情報量によるビット並べ替え（インターリーブ推定） | 効果なし | 位置埋め込みが順序を吸収する |
| mel 領域の GAN / フレーム差分損失（probe） | 変化なし | |
| 160 帯域の高解像度条件 | 悪化 | |
| 大きい識別器、位相損失 | ボコーダー上限に変化なし | |
| 学習データ 1 → 12 時間 | 3〜6 時間で飽和 | データ量よりモデル構造が効く |
| 正弦波和の調波励振を特徴量として加算 | 男性 +0.01 | |
| cyclic noise 励振 | +0.04（日本語）、英語男性は変化なし | |
| Wavehax 型励振（全倍音・実部虚部・2D 畳み込み注入） | ボコーダー上限は不変、学習後 2.56 | |
| 励振感度試験 | 教師 F0 を ×0.8、×1.25、0 にしても PESQ 不変 | 加算型の励振はボコーダーに無視される。上の 3 行は励振の効果を測定できていない |
| 事前学習データの男女比の均衡化（LibriTTS-R 追加） | 男女差は不変 | |
| 合成 hop 10 → 5 ms | 不変 | |
| 時間領域ボコーダー（PWG）の上限 | 同じ男女差 | |
| ソースフィルタ合成（硬） | 男女差 0.28 → 0.12、ボコーダー上限 3.70 → 3.26、学習後 2.44 | 周期性を構成で与えると男女差は消えるが品質上限が下がる |
| ソースフィルタ合成（柔、ゲート下限 0.5） | 上限 3.26 のまま | 上限低下は励振の微細構造（20 ms フレームの F0、硬い有声判定）に起因 |

## 主観評価

- 先行手法の構成では、コーデック自身のデコーダーより明瞭ですが、トゲのような雑音とロボット的な音色があります。
- 12 時間データと幅広フロントエンドで実用的な品質になります。正解 mel からの再合成にはロボット的な音色はありません。
- 全体の共同微調整と凍結ボコーダーの差は聞き分けられません。女性話者はコーデック自身のデコーダーを上回り、男性話者にはロボット的な音色が残ります。
- 帯域別非周期性ヘッドを加えた構成で、男女ともに実用的な品質です。男性話者ではコーデック自身のデコーダーの方が自然に聞こえる場面があります。

## 分析ツール（`scripts/diagnostics/`）

| ツール | 用途 |
|---|---|
| `pitch_accuracy.py` | 性別別 RPA / RCA / 無声化率（倍半誤りの検出） |
| `excitation_sensitivity.py` | 励振付きボコーダーが F0 を使っているか（F0 を倍率で歪めて PESQ を比較） |
| `harmonic_alignment.py` | 教師 F0 の倍音位置に対する帯域別非周期性（0.8 kHz 以上は飽和して判別力なし） |
| `phase_indicators.py`, `analyze_artifacts.py` | 位相一貫性、HNR、50 Hz バズ、スペクトログラム |
| `summarize_probes.py` | probe の val mel L1 一覧 |
| `listen_two_stage.py`, `listen_checkpoint.py` | 2 段復号の試聴、中間チェックポイントの試聴 |
