# 検討の経緯と、効かなかったこと

ここでは「次に同じ問題に当たる人」が
再試行を避けられるように、採用・不採用と理由だけを残します。設定ファイルは `configs/experiments/`、
診断ツールは `scripts/diagnostics/` です。

## 採用したもの（最終版に含まれる）

| 変更 | 効果 | 結果の場所 |
|---|---|---|
| BitToken フロントエンド（位置埋め込み＋MLP＋時間 ConvNeXt） | probe −1.2 dB、PESQ +0.25（両バックエンド） | `results/joint_controls_20k` |
| クリーン音声での mel 条件ボコーダー事前学習 | 上限 3.70、学習の初期値、録音不要 | `results/mel_istft_long_job` |
| 小型 iSTFT バックエンド（PWG の代替） | 更新 1.7 倍、推論 18 倍速、品質同等以上 | `results/frontend_benchmark.json` |
| 幅 384 / 8 ブロックのフロントエンド | +0.15 | `results/joint_b49_wide_job` |
| ビット誤り拡張 0〜2 % | BER 1〜3 % で頑健、clean は不変 |  |
| mel ブリッジ＋凍結ボコーダー | 共同微調整と同等、学習対象はフロントエンドのみ | `results/joint_b49_wide_bridge_job` |
| 周期性ヘッド（log-F0・有声度） | 全条件で +0.05 | `results/joint_b49_wide_bridge_f0_job` |
| 帯域別非周期性ヘッド（5 帯域） | さらに +0.05（2.587、最終） | `results/joint_b49_wide_bridge_f0ap_job` |

## 効かなかった・採用しなかったもの

| 試み | 結果 | 理由・教訓 |
|---|---|---|
| 論文 PWG ＋ 旧 PWG 識別器の継続 | D が学習しない（D(real)≈D(fake)） | MPD/MRD ＋ feature matching に置換 |
| PWG ＋ 事前学習済み識別器 | 不安定（D loss → 0.3） | PWG 系は打ち切り |
| インターリーブ推定（相互情報量によるビット並べ替え） | 不要 | 位置埋め込みが順序を吸収する |
| mel 領域の GAN / フレーム差分損失（probe） | 変化なし |  |
| 160 帯域の高解像度条件 | 悪化 |  |
| 大きい識別器、位相損失 | 上限に変化なし |  |
| 1 → 12 時間のデータ増 | 3〜6 時間で飽和 | データより構造 |
| 正弦波和の調波励振を特徴として加算 | 男性 +0.01 |  |
| cyclic noise 励振 | +0.04（日本語）、英語男性は無効 |  |
| Wavehax 型（全倍音・実部虚部・2D 畳み込み注入） | 上限不変、本学習 2.56 | |
| **励振感度試験** | F0 を ×0.8、×1.25、0 にしても PESQ 不変 | 加算型の励振はボコーダーに無視される。上の 3 行は励振の検証になっていなかった |
| 事前学習データの男女バランス（LibriTTS-R 追加） | 男女差 不変 |  |
| 合成 hop 10 → 5 ms | 不変 |  |
| 時間領域ボコーダー（PWG）の上限 | 同じ男女差 |  |
| ソースフィルタ合成（硬） | 男女差 0.28 → 0.12、上限 3.70 → 3.26、本学習 2.44 | 周期性を構成で与えると差は消えるが品質を失う |
| ソースフィルタ合成（柔、ゲート下限 0.5） | 上限 3.26 のまま | 上限低下は励振の微細構造（20 ms の F0、硬い有声判定）に起因 |

## 試聴で分かったこと（ユーザー判定の時系列）

- 2026-10-27: 論文構成の出力は ambe2-c より明瞭ですが、トゲ・ロボット感があります。
- 2026-10-28 朝: 12 h・幅広フロントエンドで「驚くほど良い、ほぼ実用的」。正解 mel 上限にはロボット感がありません。
- 2026-10-28 昼: 共同微調整と凍結ボコーダーは聞き分けられません。女性は ambe2-c 越え、男性はロボット感が残ります。
- 2026-10-29: 帯域別非周期性版で男女ともに良好です。完璧ではありませんが、ここを結論としました。

## 診断ツール（`scripts/diagnostics/`）

| ツール | 用途 |
|---|---|
| `pitch_accuracy.py` | 性別別 RPA / RCA / 無声化率（倍半誤りの検出） |
| `excitation_sensitivity.py` | 励振付きボコーダーが F0 を使っているか（F0 を倍率で歪めて PESQ） |
| `harmonic_alignment.py` | 教師 F0 の倍音位置に対する帯域別非周期性（0.8 kHz 以上は飽和して無効） |
| `phase_indicators.py`, `analyze_artifacts.py` | 位相一貫性、HNR、50 Hz バズ、スペクトログラム（ロボット感は説明できませんでした） |
| `summarize_probes.py` | probe の val mel L1 一覧 |
| `listen_two_stage.py`, `listen_checkpoint.py` | 2 段復号の試聴、中間チェックポイントの試聴 |
